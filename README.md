# KivoTasks

Zadania i projekty Monorise w przeglądarce, wzorem Linear: zespoły z kluczami (np. `MAG-12`), zadania ze statusami, tablica i lista, projekty, cykle, komentarze i załączniki. Logowanie, firmy, zespoły i uprawnienia pochodzą z MonoriseCore.

- Aplikacja: `kivotasks.monorise.studio`
- Strona produktu i API `/api/v1`: `kivo.monorise.studio`

Decyzje i zakres pierwszej wersji: karta produktu `11-products/kivotasks.md` i ADR w repozytorium MonoriseDocumentation. Repozytorium jest na starcie; szkielet aplikacji powstaje w kolejnym kroku.
